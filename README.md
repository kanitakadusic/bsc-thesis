# Vector Databases

This repository contains my BSc thesis _Vector Databases: Use Cases, Algorithms and Key Features_ organized into three main chapters:

- _Theoretical Background_ - Covers embeddings, distance metrics, and (approximate) nearest neighbor search.
- _Selected Algorithms_ - Discusses ANN algorithms: LSH (hash-based), Annoy (tree-based), and HNSW (graph-based).
- _Vector Databases in Practice_ - Demonstrates usage of FAISS, Milvus, and Weaviate for similarity search.
